# 3D扁平化数字地球 - 最终技术规格与复刻指南

本文档基于 `Three.js r173` 和 `Vue 3`，详细说明了如何实现一个零层级感、锐利描边、具有 2.5D 光影体积感且完全交互的现代扁平化地球。

## 一、 最终视觉效果基准

- **地球基色**：从浅蓝紫 (`#8A8CFC`) 对角线渐变至 深蓝紫 (`#4C5FF0`)。
- **自定义聚光**：左上前方 (`vec3(-0.3, 0.8, 0.6)`) 打出极亮且收拢的冰蓝高光 (`#E0EAFF`)。
- **国家填充**：陆地底色为 15% 透明度纯白；鼠标悬浮高亮平滑至 80% 透明度纯白。
- **国界描边**：100% 纯白实线，边缘严格抗锯齿（完全矢量）。
- **交互逻辑**：
  - 自由拖拽旋转带有惯性衰减（`Velocity * 0.95`）。
  - 纵向视角软钳制在 `±0.4 rad`（约 ±23°），锁定两极盲区，聚焦核心人类大陆。
  - Hover 显示精准的国家中文名称 Tooltip。

## 二、 核心架构：改进型双轨渲染 (Two-Layer Physical Architecture)

经历 5 轮方案迭代（含 Canvas合成、Shader 边缘检测、几何包裹等），最终收敛于**性能最高、矢量清晰度最完美**的物理双层架构：

### 1. 底层：ShaderMaterial 球体 (Radius = 1.0)
负责所有的“面”处理，包括海洋光影和陆地透明度计算。不使用几何体细分国家，杜绝穿模。

### 2. 表层：Line 矢量线 (Radius = 1.002)
负责所有的“线”处理。使用 `THREE.Line` 基于 GeoJSON 的端点渲染。由于采用了 `1.002` 这个极其精确的微距，它既在数学上避开了 WebGL 深度缓冲（Z-Buffer）的竞争导致闪烁，又在视觉透视上造成了“完全紧贴零层距”的错觉。

## 三、 核心技术难点与解决方案

### 1. 根除“黑边阴影”与边缘模糊
**问题**：直接在 Canvas 里画 `rgba(255,255,255,0.15)` 的国家面片，当它作为纹理贴到地球上时，抗锯齿边缘会与默认背景的“透明黑 (`rgba(0,0,0,0)`)”发生线性插值，导致大陆边缘出现恶心的黑色轮廓。
**解决**：
- 在 2D Canvas 中**只画 100% 纯白**（充当纯粹的 Mask 掩码），不画透明度。
- 用 `ctx.fillStyle = 'rgba(255,255,255,0)'` （纯白透明）填满海洋背景。
- 在纹理初始化时关闭 `generateMipmaps = false`。
- 在 Shader 中，利用 `fwidth` 与 `smoothstep` 截断灰度过渡带，将它强行压缩回清晰的 0/1 二值边界：
```glsl
float sharpenMask(float raw) {
  float aa = max(fwidth(raw) * 0.75, 0.001);
  return smoothstep(0.5 - aa, 0.5 + aa, raw);
}
```

### 2. 彻底解耦的 Hover 高亮
**问题**：每次鼠标移动重绘 2048x1024 的 Canvas 极耗 CPU。
**解决**：
- 将“全人类陆地 (`uCountryMask`)” 和 “当前 Hover 国家 (`uHoverMask`)” 拆分为两张独立的 Texture。
- 基础遮罩只需初始化一次。
- 鼠标移动命中时，只擦除并重绘 `HoverCanvas` 中的单个多边形。
- 在 Shader 侧动态混合叠加计算最终透明度：
```glsl
float fillAlpha = countryMask * 0.15 + hoverMask * (0.8 - 0.15);
fillAlpha = clamp(fillAlpha, 0.0, 1.0);
```

### 3. 精准的 Hover 拾取防偏
**问题**：国界线过细无法使用原生的 Raycaster 命中，而球体只是一整张贴图，不知道具体的国家归属。
**解决**：
- 渲染第三张隐藏的 1024x512 Canvas (`ID Map`)。
- 为 GeoJSON 中的每个国家分配一个从 `0` 开始的索引，将索引编码为 RGB 颜色画入地图（如 `rgb(1,0,0)` 就是 Index 1）。
- 海洋填充 `#ffffff`（解码后超纲作为哨兵值）。
- 鼠标 Raycaster 拿到球面的 `uv` 坐标后，反向读取 ID Map 的单个像素 RGB 进行解码，达到 100% 精准、无视多边形复杂度的完美拾取。

### 4. 共享边界去重亮度加倍
**问题**：邻国边界（如美加边境）共享坐标，原生绘制会执行两遍 `stroke()` 导致重合处变亮。
**解决**：
取消基于国家的循环独立画线，将所有的 GeoJSON Line 点位推入**同一个全局数组**，最终合并构建一整条巨大的 `BufferGeometry` 并执行单次实例化渲染。

## 四、 本地纯前端复刻指南

如果无需 Python 后端，纯前端 Vite 项目复刻极简流程：

1. **环境准备**：`npm install three`
2. **数据挂载**：
   将 `ne_110m_admin_0_countries.json` 放进本地 Vite 项目的 `public` 目录下。
3. **接口修改**：
   将 App.vue 中的 `fetch('/api/geojson')` 改为 `fetch('/ne_110m_admin_0_countries.json')`。
4. **运行**：`npm run dev`，即可得到具备所有灯光、遮罩、悬浮与转动惯性的三维地球。
